# DESIGNLAB UA — від першої лінії до професійного дизайну

Інтерактивна академія графічного дизайну **українською мовою**. 44 модулі по 9 рівнях,
Color Lab з реальним генератором палітр, портфоліо, прогрес, XP, стрік, досягнення,
словник термінів і кар'єрна готовність.

Формат навчання на кожному модулі: **прочитав теорію → пройшов міні-тест → виконав практику
→ позначив пройденим.**

---

## 1. Що це за проєкт

Це MVP (Minimum Viable Product) — повністю робочий застосунок, який:

- навчає графічному дизайну людину без досвіду;
- має 44 модулі, поділені на 9 рівнів (Foundations, Design Fundamentals, Graphic Design,
  Digital Design, Print & Physical, Illustration & Image, Motion & 3D, Advanced, Professional);
- **усі 44 модулі мають повний контент**: розгорнуту теорію (не конспект, а пояснення
  принципів із прикладами), ключові принципи, типові помилки, список тем, практичне
  завдання (де воно передбачене), критерії самоперевірки практики і міні-тест;
- має робочий **Color Lab** (компліментарна, аналогова, тріадна, тетрадна, split-complementary
  й монохромна гармонії — генеруються в реальному часі з HSL, без заглушок);
- має робоче **портфоліо**, **прогрес/XP/рівні/стрік**, **систему досягнень**, що
  розблоковуються на основі реального прогресу, і **кар'єрну готовність**, що рахується
  чесно від пройдених модулів (без обіцянок на кшталт "ви гарантовано готові").

Технічний стек: **React 18 + Vite**, React Router, чистий CSS (без Tailwind/UI-бібліотек).
Прогрес, портфоліо, палітри й локальний акаунт зберігаються в `localStorage` браузера.

## 2. Встановлення Node.js

Потрібна версія Node.js 18 або новіша.

1. Перейди на https://nodejs.org
2. Завантаж і встанови LTS-версію для своєї ОС
3. Перевір встановлення:

```bash
node -v
npm -v
```

## 5. Як додати контент у модуль (теорію, тест)

Усі модулі знаходяться в одному файлі `src/data/modules.js` як масив `MODULES`. Кожен
модуль — об'єкт такого вигляду:

```javascript
{
  id: 13,                       // номер модуля — унікальний, 1–44
  level: 'I',                   // літера рівня (A–I), див. src/data/levels.js
  title: 'Adobe InDesign',

  theory: 'Короткий абзац теорії простими словами...',

  topics: [
    'Тема 1',
    'Тема 2',
  ],

  practice: 'Опис практичного завдання.' , // або null, якщо практики немає

  quiz: [                        // необов'язково — якщо є, показується міні-тест
    {
      question: 'Питання?',
      options: ['Варіант А', 'Варіант Б', 'Варіант В'],
      correctAnswer: 1,          // індекс правильної відповіді (рахуючи з 0)
    },
  ],
}
```

Щоб додати тест до модуля, який його ще не має (13–44), просто додай поле `quiz` до
відповідного об'єкта в `src/data/modules.js` — сторінка модуля (`src/pages/Module.jsx`)
автоматично покаже компонент `Quiz`, без будь-яких інших змін коду.

## 6. Як додати термін у словник

Відкрий `src/data/glossary.js` і додай новий об'єкт у масив `GLOSSARY`:

```javascript
{
  slug: 'my-term',        // унікальний ідентифікатор без пробілів
  en: 'My Term',
  ua: 'Мій термін',
  simple: 'Просте пояснення.',
}
```

---

## 7. Як додати досягнення

Відкрий `src/data/achievements.js` і додай об'єкт у масив `ACHIEVEMENTS`:

```javascript
{
  slug: 'my-achievement',
  title: 'Назва досягнення',
  description: 'Умова людською мовою.',
  check: (stats) => /* поверни true/false на основі stats */,
}
```

Доступні поля `stats`: `completedIds`, `completedCount`, `total`, `levelDone` (мапа
рівень → чи весь рівень пройдено), `portfolioCount`, `paletteCount`, `streak`.

---

## 8. Як змінювати дизайн

Уся тема (кольори, шрифти) зібрана в `src/styles/tokens.css` як CSS-змінні. Наприклад,
щоб змінити акцентний колір:

```css
:root {
  --accent: #3E37E0; /* заміни на свій колір */
}
```

Стилі окремих сторінок і компонентів — у `src/styles/app.css`.

## 12. Де виконати практичне завдання — інструменти і Sketch Pad

Для кожного з 23 модулів із практичним завданням у блоці "ПРАКТИКА" тепер показано:

- **Бейджі інструментів** — зелені (безкоштовні: Figma, Inkscape, GIMP, Krita, Blender,
  Photopea, Canva, Scribus, Coolors) і жовті (платні: Adobe Photoshop/Illustrator/InDesign) —
  з прямим посиланням на офіційний сайт кожного інструменту.
- **"🖊 Створити ескіз у застосунку"** — вбудований мini-редактор (`src/components/SketchPad.jsx`)
  з інструментами пензля, лінії, прямокутника, еліпса, тексту й ластика, заливкою фігур,
  вибором кольору (пресети + свій колір), кольором фону, сіткою-орієнтиром для композиції,
  undo/redo та експортом у PNG — без встановлення стороннього софту. Результат зберігається
  одним кліком у Портфоліо як зображення (PNG, base64 в `localStorage`) або завантажується
  на диск кнопкою "Завантажити PNG".
- **"Додати виконану роботу в портфоліо"** — переносить у форму портфоліо назву модуля
  й тег, щоб не вводити їх вручну після виконання завдання в зовнішньому інструменті.

Sketch Pad підходить для швидких ескізів (композиція, лого-начерки), але не замінює
повноцінний векторний/растровий редактор для фінального виконання складніших завдань
(упаковка, багатосторінковий журнал, 3D) — для них призначені бейджі інструментів вище.

## 13. Як працює міні-тест і нарахування балів

Тест у модулі — покроковий (одне питання за раз):

- Неправильна відповідь підсвічується червоним і **не дає перейти далі** — можна
  спробувати ще раз стільки разів, скільки потрібно.
- Кнопка **"Далі"** активна лише після правильної відповіді на поточне питання.
- Після проходження всіх питань модуля нараховується **+20 XP** (одноразово за модуль,
  повторне проходження тесту XP вдруге не додає).
- Стан тесту скидається при переході на інший модуль (react `key={module.id}` на
  компоненті `Quiz`) — раніше обрані відповіді одного модуля не "просвічують" у тесті
  іншого модуля.

## 14. Режим презентації (відео-урок без відеофайлу)

"🎬 Режим презентації" (`src/components/PresentationMode.jsx`) — це чесна заміна відео-уроку
там, де немає можливості рендерити реальні відеофайли: слайди з теорією, ключовими
принципами, типовими помилками, практикою і прикладом виконання модуля автоматично
перемикаються синхронно з голосовим озвученням (той самий Web Speech API, що й у
"🔊 Прослухати теорію"). Керування: play/pause, вперед/назад, точки прогресу зверху.
Якщо озвучення не підтримується браузером — слайди все одно гортаються вручну.

Кнопка "🎥 Знайти відео на YouTube" відкриває пошук за назвою модуля — конкретне відео
свідомо не підставляється, бо немає способу гарантувати робоче й релевантне посилання.

## 15. Чесні обмеження — що курс НЕ замінює

Це важливо розуміти до того, як вважати курс "достатнім для роботи":

- **Немає перевірки практичних робіт людиною.** Модуль показує критерії самоперевірки
  (`selfCheck`), але ніхто не подивиться на реальний виконаний постер/лого і не дасть
  предметний фідбек. У дизайні як навичці цикл "зробив → отримав критику → переробив"
  критичний — його не замінює жоден текстовий курс. Це прямо позначено в оригінальному
  ТЗ як `TODO: IMPLEMENT DESIGN REVIEW ENGINE`.
- **Немає навчання самому софту.** Курс пояснює, для чого потрібен інструмент і які в
  ньому концепції (шари, компоненти, boolean-операції), але не вчить, куди саме клікати
  в Figma чи Illustrator — це окрема моторна навичка, яку напрацьовують практикою в самій
  програмі (YouTube-туторіали з конкретного софту — гарне доповнення).
- **Немає реальних клієнтів і репутації фрилансера** — це формується лише роботою з
  реальними людьми, не курсом.
- Авторизація локальна (без пароля й сервера) — розрахована на одного користувача в
  одному браузері; архітектура (`AuthContext`) дозволяє підключити реальний бекенд пізніше.
- Немає реального завантаження файлів дизайну в портфоліо (лише текстовий опис проєкту) —
  для файлів знадобиться бекенд зі сховищем (S3/аналоги) і валідацією типів/розміру.
- Немає AI-інтеграцій (Модуль 34 — теоретичний): підключення реального AI-провайдера
  потребує бекенд-проксі для ключів API.

**Чесний висновок**: цей курс дає повноцінну теоретичну базу і структуру практики —
достатню, щоб системно опанувати принципи дизайну. Але для реальної готовності до роботи
йому бракує зовнішнього фідбеку (ментор, дизайн-спільнота, реальні клієнти) — жоден
текстовий курс сам по собі цього не замінює.
