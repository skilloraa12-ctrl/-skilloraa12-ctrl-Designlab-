# Відео-уроки

Це пілот на 2 уроках: **id 1** («Що таке Web Design») і **id 2** («Як
працює веб: браузер, сервер, клієнт»), обидва — `lessons/web-design-basics.js`.

## Що треба покласти сюди

Для кожного пілотного уроку — два файли з назвою за `id` уроку:

```
public/lesson-videos/1.mp4   ← відео до уроку id 1
public/lesson-videos/1.jpg   ← обкладинка (кадр-заставка), необов'язково
public/lesson-videos/2.mp4   ← відео до уроку id 2
public/lesson-videos/2.jpg   ← обкладинка, необов'язково
```

Більше нічого в коді міняти не треба — щойно файл `<id>.mp4` з'явиться
тут, плеєр на сторінці уроку сам його підхопить (`Module.jsx` →
`LessonVideo.jsx`). Поки файла нема — блок з відео просто не показується
(жодної зламаної кнопки чи порожнього плеєра відвідувач не побачить).

## Як зробити відео зі звуком

Найпростіший шлях без додаткових витрат:

1. Згенеруй **візуальний** кліп (без звуку) у Kling AI або Google AI
   Studio (Veo) за коротким сценарієм уроку (кілька сцен по 5-10 сек).
2. Озвуч текст уроку українською через уже вбудований у сайт безкоштовний
   голос (кнопка «Прослухати урок» на сторінці уроку, self-hosted Piper
   TTS) — або будь-яким іншим голосом.
3. Зведи відео + звук в один файл (CapCut, DaVinci Resolve, або навіть
   Kling/Veo, якщо там є вбудований аудіо-трек — Veo вміє генерувати
   звук/мову одразу разом із відео, це може зекономити крок 2-3).
4. Експортуй як `.mp4`, поклади сюди з назвою `<id>.mp4`.

## Формат

- Формат: `.mp4` (H.264) — найширша підтримка браузерами.
- Короткий ролик (орієнтовно 30-90 сек на урок) — досить, щоб пояснити
  суть, а не переказати весь текст уроку.
- Розмір файлу: враховуй, що сайт на GitHub Pages — великі відео
  (десятки МБ на урок) сповільнять завантаження сторінки й збільшать
  розмір репозиторію. Якщо відео стають важкими (>250 уроків у
  перспективі), краще перейти на YouTube (unlisted) і просто вставляти
  посилання — про це можна домовитись окремо, коли пілот підтвердить
  формат.

## Коли пілот спрацює на обох уроках

Дай знати — розширимо на більше уроків тим самим способом (просто
`video: true` в лесон-файлі + відповідні `<id>.mp4`/`<id>.jpg` тут).
